### 1. Основные принципы ООП:
- **Инкапсуляция**: Сокрытие внутренней реализации объекта и предоставление доступа к данным только через методы (геттеры и сеттеры).
- **Наследование**: Возможность создания нового класса на основе существующего с использованием ключевого слова `extends`. Позволяет повторно использовать код.
- **Полиморфизм**: Возможность объектов с одинаковым интерфейсом вести себя по-разному. В Java реализуется через переопределение методов (динамический полиморфизм) и перегрузку методов (статический полиморфизм).
- **Абстракция**: Создание упрощённой модели объекта, которая выделяет только важные аспекты и игнорирует несущественные детали. Реализуется через абстрактные классы и интерфейсы.

---

### 2. Иерархия наследования и методы класса `Object`:
- В Java все классы неявно наследуются от класса `Object`.
- **Методы класса `Object`**:
    - `toString()`: Возвращает строковое представление объекта.
    - `equals(Object obj)`: Сравнивает объекты на равенство.
    - `hashCode()`: Возвращает хэш-код объекта.
    - `getClass()`: Возвращает объект класса `Class`, представляющий тип объекта.
    - `clone()`: Создает и возвращает копию объекта.
    - `finalize()`: Вызывается перед удалением объекта сборщиком мусора (не рекомендуется использовать).
    - `wait()`, `notify()`, `notifyAll()`: Используются для работы с потоками.

---

### 3. Интерфейс и абстрактный класс:
- **Интерфейс**: Это контракт, который определяет набор методов, которые должны быть реализованы классами. Интерфейсы могут содержать только абстрактные методы (до Java 8), а также `default` и `static` методы.
- **Абстрактный класс**: Это класс, который может содержать как абстрактные методы (без реализации), так и методы с реализацией. Нельзя создать экземпляр абстрактного класса.

---

### 4. Конструкторы, поля и методы в интерфейсах и абстрактных классах:
- **Интерфейс**:
    - Не может иметь конструкторов.
    - Может содержать только `public static final` поля (константы).
    - Может содержать `default` и `static` методы (с Java 8).
- **Абстрактный класс**:
    - Может иметь конструкторы (для инициализации полей).
    - Может содержать поля и методы с любой областью видимости.
    - Может содержать как абстрактные, так и обычные методы.

---

### 5. Enum:
- **Enum** — это специальный тип данных, который представляет собой набор констант.
- Отличие от класса: Enum не может наследоваться, но может реализовывать интерфейсы.
- Может содержать методы, конструкторы и поля.
- Конструкторы Enum всегда приватные.

---

### 6. Модификаторы доступа:
- **public**: Доступен из любого класса.
- **protected**: Доступен внутри пакета и для подклассов.
- **default (package-private)**: Доступен только внутри пакета.
- **private**: Доступен только внутри класса.

---

### 7. Конструкторы:
- Конструкторы могут иметь модификаторы `public`, `protected`, `private` или `default`.
- Конструкторы не наследуются и не переопределяются, но могут вызываться в подклассах с помощью `super()`.

---

### 8. Реализация двух интерфейсов с одинаковым методом:
- Если два интерфейса имеют метод с одинаковой сигнатурой, то в классе достаточно реализовать этот метод один раз. Если методы имеют разные реализации по умолчанию (`default`), то нужно явно указать, какой метод использовать, или переопределить его.

---

### 9. Статический и динамический полиморфизм:
- **Статический полиморфизм**: Реализуется через перегрузку методов (compile-time).
- **Динамический полиморфизм**: Реализуется через переопределение методов (runtime).

---

### 10. Члены класса:
- Поля (переменные).
- Методы.
- Конструкторы.
- Вложенные классы и интерфейсы.
- Блоки инициализации.

---

### 11. Переопределение и перегрузка методов:
- **Переопределение**: Изменение реализации метода в подклассе с сохранением сигнатуры метода.
- **Перегрузка**: Создание метода с тем же именем, но с другой сигнатурой (разные параметры).

---

### 12. JVM, JRE, JDK:
- **JVM (Java Virtual Machine)**: Виртуальная машина, которая выполняет байт-код Java.
- **JRE (Java Runtime Environment)**: Среда выполнения, включающая JVM и стандартные библиотеки.
- **JDK (Java Development Kit)**: Набор инструментов для разработки, включающий JRE, компилятор и другие утилиты.

---

### 13. Classpath и именование пакетов:
- **Classpath**: Путь, по которому JVM ищет классы и ресурсы.
- **Именование пакетов**: Обычно используется доменное имя в обратном порядке (например, `com.example.myapp`).

---

### 14. Интерфейсы `Comparator` и `Comparable`:
- **Comparable**: Используется для естественного порядка сортировки (метод `compareTo`).
- **Comparator**: Используется для создания пользовательского порядка сортировки (метод `compare`).

---

### 15. Класс `String` и пул строк:
- `String` — это неизменяемый (`final`) класс.
- Пул строк (`String Pool`) — это область в памяти, где хранятся строковые литералы для оптимизации памяти.
- Метод `intern()` позволяет поместить строку в пул или получить ссылку на существующую строку.

---

### 16. Зарезервированные слова:
- **super**: Ссылка на родительский класс.
- **this**: Ссылка на текущий объект.
- **class**: Используется для создания классов.
- **instanceof**: Проверяет, является ли объект экземпляром определённого класса.

---

### 17. Массивы в Java:
- Массивы — это объекты, которые хранят элементы одного типа.
- Длина массива фиксирована и задаётся при создании.
- Массив нулевой длины допустим, но не может быть расширен.

---

### 18. Этапы создания и запуска блоков и конструкторов при наследовании:
1. Статические блоки родительского класса.
2. Статические блоки дочернего класса.
3. Нестатические блоки инициализации родительского класса.
4. Конструктор родительского класса.
5. Нестатические блоки инициализации дочернего класса.
6. Конструктор дочернего класса.

---

### 19. Поведение `break` и `continue` в цикле:
- **break**: Прерывает выполнение цикла.
- **continue**: Пропускает текущую итерацию и переходит к следующей.

---

### 20. Generics:
- Generics позволяют создавать типизированные классы, интерфейсы и методы, что повышает безопасность типов и уменьшает необходимость приведения типов.

---

### 21. Ключевое слово `final`:
- Применяется к классам, методам и переменным.
- **Класс**: Не может быть унаследован.
- **Метод**: Не может быть переопределён.
- **Переменная**: Не может быть изменена после инициализации.

---

### 22. Optional:
- `Optional` — это контейнерный объект, который может содержать или не содержать значение. Используется для избежания `NullPointerException`.
